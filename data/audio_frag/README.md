# data/audio_frag/ -- TISMIR salsa audio fragments (local only)

The unzipped `audio_fragments.zip` from the TISMIR 2024 salsa dataset
(Zenodo 13120822): short fragments of 124 songs with beat annotations but no
1-vs-5 labels (~340 MB). Used only in the Stage A probe (NOTES 3); the beat
annotations themselves are tracked in `data/salsa_ismir/`.

- Read by: `experiments/stage_a_probe.py`
